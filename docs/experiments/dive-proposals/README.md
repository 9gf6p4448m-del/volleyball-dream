# 魚躍「現代貼地救球」提案（2026-09-27，分支 `feat/dive-proposals`，僅供挑選、未合併）

品味題：以下三案讓使用者用眼睛挑，不代表已選定。預設遊戲行為不變（只有網址帶 `?dive=` 才走提案）。

- 比較圖：`dive-compare-portrait.png`（直式 390×844 為主）、`dive-compare-desktop.png`（桌機 1280×720）。欄＝現行｜A｜B｜C 高球｜C 貼地球；列＝起動／撲出／觸球／著地滑行／撐地收腿／起身；每格上幾何人、下寫實人。
- 動圖：`dive-geo.gif`、`dive-real.gif`（直式側面，現行｜A｜B｜C 四欄同步，逐幀 60fps 每 2 幀取 1）。
- 看動態：`?mode=divelab&dive=now|a|b|c`（`&fig=real` 寫實人、`&cam=front|game` 換鏡頭、`&ball=0.2` 看 C 的貼地球分支；畫面下方有按鈕可切）。比賽中：任何原網址加 `&dive=a`（或 b、c）。

## 三個方案

**A sprawl 滑撲**
- 像：現代防守的 sprawl——弓步壓低、雙臂併攏平台貼地前伸、胸腹著地往前滑（IYV 描述「比跨步更快降到地面、平台伸到球下」）。
- 「動作太奇怪」：不再以腳為支點整根木板前倒；先弓步再趴，手臂是併攏的平台（現行版雙腕相距 0.8 m、是張開的）。
- 「像殭屍」：現行版趴著往後倒滑 1.35 m、身體還會跟著飛走的球在地上轉；A 的骨盆只前移約 0.5 m，回位發生在「推地收膝成跪姿→站起」那一段，撲出方向鎖定為出手瞬間的人→球方向。
- 「爬起太快」：總長仍是 sim 的 0.7 s（時序不准改），只能把起身拆成推地→收膝→站起三段讓它讀得出過程；本質上仍是 0.7 s 內站起來。
- 已知缺點：側收的前腳是「外展＋屈膝」，小腿翹起、不是真人那種整條腿內側貼地（缺髖外旋欄位）。

**B pancake 手掌貼地**
- 像：pancake——低平飛撲、全身幾乎與地平行、慣用手伸到最遠平貼地板（LEB2025「手掌貼地讓球從手背彈起」），另一手斜前撐地緩衝。
- 「太奇怪」：比 A 更早躺平（0.10 s 已貼地），畫面最乾淨，但動感最「平」；「殭屍」「爬起」處理同 A。
- 已知缺點：①骨架沒有前臂旋前／上臂內旋，**做不出「掌心朝下」**——幾何人的手是球體看不出來，寫實人的手是側立的；②sim 的魚躍 84% 在球高 1.0–1.14 m 出手（下方量測），手貼地的觸球幀和 sim 真正觸球的高度對不上。

**C 依球高自動切換**
- 規則：sim 出手那一刻球高 ≥ 0.45 m 走「跨步平台墊→順勢趴成 A 的滑撲」，觸球幀平台在腰胸高；< 0.45 m 改走 B 的 pancake。球高由 matchView 讀 `gameState.ball.y`（唯讀，不改 sim）。
- 和三點抱怨的關係同 A；多出來的是觸球幀跟 sim 的球高比較對得上。
- 已知缺點：實際比賽約 90% 會走高球分支（外觀近似 A，差在觸球那 0.1 s），貼地球分支很少見。

## 共通做法與取捨
- 時序：三支序列 `dur 0.72／jump 0／無 hit`，與現行 `dive` 同；sim 未改。sim 的觸球其實發生在魚躍第 0 幀（出手即判定），動畫「觸球」關鍵幀在 0.10 s——這是現行版就有的時差，本卷不動。
- sim 倒地期間人不動（`game.js:549`）：撲出位移全是表現層，root 曲線在倒地結束時回到 sim 位置、前傾歸零。
- 接地補償：root 擺好後量全身最低點，低於 −0.02 m 才往上抬（只抬不壓）。因此「不入地」對提案是**構造保證**；鑑別力在對向條件（見下）。交還給遊戲待命姿勢時會有約 4.1 cm 的單幀下沉（量測值 0.0408 m）——遊戲既有待命姿勢的鞋尖本來就在 −0.059 m（範圍外，未處理）。
- 左右語意（`tools/dive-proposal-check.mjs` 實測，不從既有 POSES 推論）：肩 z 正＝手往 +X；角色右側在 −X ⇒ `rSh z` 正＝右臂內收、`lSh z` 負＝左臂內收；`pelvis y` 正＝右髖往前；髖 x 負＝大腿前抬；膝 x 正＝正常屈膝。
- 新增姿勢欄位 `rHipX/lHipX/rKneeX/lKneeX/rHipZ/lHipZ`（疊加在 crouch 換算上；既有姿勢缺欄位＝0，逐值不變；左手選手左右對調、髖 z 取反）。

## 回歸底線
- 幾何人：`node tools/dive-proposal-check.mjs --json docs/experiments/dive-proposals/geo-check.json` → `geo-check.txt`。三案 × 左右手，魚躍窗 43 幀全過：F1 膝不反折、F2 鞋盒 8 角點或貼地軀幹 ≥ −0.03 m、F3 全身每個部件 ≥ −0.03 m（加嚴）、G 趴地段軀幹 ≤ 0.08 m、H 每幀全身最低點 ≤ 0.03 m（防浮空）。突變驗紅：補償目標改 −0.5（等於關掉）→ F2/F3 紅；改 +0.1（浮起）→ G/H 紅。現行版列為對照（全身最低 −0.461 m，手沒入地板）。
- 寫實人（`tools/dive-proposal-shots.mjs` 逐幀量）：手部頂點質心離腕最大 0.111 m（≤ 0.15，第一階段 A2(e) 定義，176 幀全幀＋關鍵幀）；提案全身最低 −0.028 m；頁面錯誤 0。預覽中寫實人不跑腿部 IK（IK 是為站姿設計的）。
- `npm test`：2603 條、2601 過、2 敗＝A23a、A23b（與基準相同），尾段見 `npm-test-tail.log`。

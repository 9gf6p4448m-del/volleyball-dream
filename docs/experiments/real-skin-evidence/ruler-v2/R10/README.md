- 突變內容（`mutants/mut-torso.diff`）：把「δ>2 cm」換成「pelvis／spine／spineUpper 權重和 >0.5 的上臂頂點數」，δ 最大值固定為 0。
- 基準也用同一份突變工具在 8720597 重新產生（`mt-base-*`）。
- 突變版只放在臨時副本，跑完即刪除。

| | F K4b（右、左） | 上限 | 判定 | 突變被抓到？ |
|---|---|---|---|---|
| 20k | 81、71 | 50、48 | 紅（9 幀不過） | **否**：F 仍紅 |
| 5k | 18、17 | 34、35 | 綠（9 幀全過） | 是：F 轉綠 |

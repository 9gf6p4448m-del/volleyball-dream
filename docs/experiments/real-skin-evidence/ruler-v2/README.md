## 二、量法（只換「在內或在外」）

| 項目 | 舊量法（lib.metricPenetration） | 新尺（`tools/real-skin-penetration-v2.mjs`） |
|---|---|---|
| 內外判定 | 最近點的內插頂點法線定號；最近點在子集開口邊＝「無法判定」不計 | **generalized winding number**：w(p)＝Σ Ω_t(p)／4π（Jacobson 2013；立體角 Van Oosterom–Strackee 1983），**w>0.5＝在內** |
| 深度 | 到最近被穿入表面三角形的距離（搜尋上限 25 cm） | 同（精確最近點，不設上限） |
| 被穿入表面 | (b) `R.torsoTris`；(e) 主骨 ∈ {pelvis, rHip, lHip} | 同一份（V0 證明逐三角形同數、舊值 36/36 重現） |
| 手臂頂點、分區 | `R.armVerts`；手臂部位→最近面綁定高度（胸／腹／臀腿） | 同 |

選 GWN 的理由：①它是整個子集表面的立體角積分，不看最近點的局部法線，凹處遠處最近點的法線不再能把外面的點翻成裡面；
②S_b、S_e 都是從整隻白模切出來的**開放**曲面，GWN 對開口有定義（開口處由調和延拓「補膜」，w＝0.5 等值面），不需要「無法判定」；
③沒有可調參數（0.5 是方法本身的門檻）；④固定順序精確加總，逐位元可重現。

用法：`node tools/real-skin-penetration-v2.mjs --faces=20k|5k [--json=…] [--txt=…] [--baseline=ruler-v2/before-<faces>.json]`
（`--baseline` 另印 S2(i) 18 項不退步比較，深度照驗收檔比 0.1 cm）。輸出同表並列新舊值與分區，另有兩個**診斷欄**（不影響判定）：
「開口」＝新計入點中最近點落在 S 開口邊的點數／最深（舊法一律不計的點）、「近½」＝w∈(0.4,0.6) 的頂點數（姿勢微調就可能翻面）。

## 五、已知特性與限制（量尺的，請修模型的人知道）

1. **開口補膜**：S_b 的開口＝頂部 y 1.55＋兩肩 |x|＝0.21 切口與手臂頂點排除（一圈，低到腋窩 y≈1.27）、底部 y 0.75＋臀側 |x|＝0.21 切口（高到 y≈1.0）；
   S_e 的開口＝腰（y≈1.07–1.13）與兩膝。GWN 在開口處的 w＝0.5 面大致就是切口平面。所以肩頭／腋窩上方、臀側切口內側的手臂點會被計入 (b)，
   **深度量到最近 S_b 三角形（常是切口邊），不是量到真皮**——可能比「離真皮的距離」大（頂點 1778：到 S_b 10.2 cm、到肩頭皮 9.1 cm）。
   這是驗收檔「深度＝到最近軀幹面」與 S_b 切法的直接結果，新尺照定義做、沒有另加規則；診斷欄「開口」逐幀列出這類點的數量與最深。
   量化（8720597 20k，暫時探針，未提交）：把「到 S 深度」與「到去臂身體最近皮（含肩頭臂根）的距離」逐點比，**每幀最深值多半相同**；
   差最多的是 K4b (b)（開口點最深 9.4 vs 8.3 cm、非開口點 10.2 vs 9.5 cm）與 K4c (b)（7.1 vs 5.7、7.7 vs 7.1 cm），
   逐點最多多 4.0 cm（開口點）／3.6 cm（非開口點）；(e) 在 20k、5k 的 9 幀逐點差都 ≤0.1 cm。舊量法對它「判定得了」的點用的也是同一個深度定義。

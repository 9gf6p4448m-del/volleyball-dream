# Phase 4 週次切分總覽(W1–W4)— 2026-07-26

> 依賴排序原則:時間系統是一切的地基 → 身高長在時間軸上 → 位置長在創角上 →
> 賽制/場館/數據是體驗層,最後疊。每週結尾照慣例:試玩 → 狀態快照 → 回饋驅動下週 prompt。
> 憲法=`phase4-decisions-RESOLVED.md`,每週 prompt 引用,不重述全部細節。

## W1|時間系統(畢業/新生/年級/ace 遞補)

**主題:讓時間真的會走。**

- STARTER_DEFS 全員年級回填(大山+一名非 MB 兩翼戲少者=三年級;第二名定名後回填憲法)
- RECRUIT_DEFS 七人年級回填(配比原則:條件越苛越不可為三年級)+情蒐/招募面板標年級
- 賽季收束 → 畢業儀式事件(具名台詞;三年級招募生同walk此流程)→ 新生入學 → 下屆開幕
- 混合制新生:手寫新生資料結構+第 2 屆 MB 接班新生人設稿(名字用字族,人設「前輩的影子」)
  +程序生成補位員(字族抽名、種子決定論)
- 對手 ace 畢業遞補(applyPoaching 同款純函式轉換)+A1 對手板凳:七隊 reserves 擴充至
  可換人規模(2→4 名,同批人=遞補池),對手比賽中疲勞換人接線
- 畢業播報「舊王牌去向」一句話伏筆
- 測試:年級/畢業/遞補/新生決定論全鏈;naming.test 擴充涵蓋新增名單

**驗收重點**:打完一屆 → 看見畢業儀式 → 第 2 屆開幕名冊正確換血(我方+對手)。

## W2|身高創角+成長曲線

**主題:以真實的自己追排球夢——招牌復活。**

- 創角流程:輸入真實身高 → 誠實位置建議(建議邏輯+教練台詞,含縫隙 3 培育話術)→
  志願登記 → OH 出道
- sim 接身高參數:攔網高度/扣球點/防守範圍;`height.timeline` 首次消費
- 三年成長曲線:賽季過渡時按青春期曲線成長(種子決定論)+「你長高了」儀式演出
- 平衡治具重建:身高變數進場後 n=150 基準全重跑,校準到 W8 結案帶(決賽帶 20%/奪冠 5-7%)
- 測試:身高→參數映射、成長曲線決定論、建議邏輯邊界(極矮/極高輸入)

**驗收重點**:創兩個不同身高的角色,場上攔網/扣球體感有別;過一屆身高有變並有演出。

## W3|五位置工程(S/MB/OPP;L 設計先行)

**主題:位置即職業,工程一次建完。**

- S 分配決策玩法:trust 反轉(你分給 AI),分配面板+一傳品質分支下的選項池
- MB 攔網讀心玩法:對手舉球讀取+快攻時機決策
- OPP:共用 OH 架構微調(後排 D 球權重等)
- 開放旗標系統:位置驗證狀態管理+「教練談話」轉位事件框架
- 縫隙 1 五組被取代者配對:阿哲組=層次二表現讀取導師(3-5 條規則觸發,吃 W4 box score
  介面——W3 先定介面契約,W4 接數據);其他四組=層次一敘事稿
- **L 玩法:本週與 Sawmah 半場設計討論定案後才實作**(排本週最後或順延 W4)
- 平衡:S/MB/OPP 各自獨立跑治具
- 測試:各位置 Intent 流、決策點交接(AI→玩家)決定論、旗標系統

**驗收重點**:Sawmah 逐位置試玩,驗一個開一個;結案至少 1-2 位置開放。

## W4|賽制+場館+數據+結算

**主題:重量感——大日子要像大日子。**

- 分級賽制:關鍵戰三局兩勝/冠軍戰五局三勝決勝局 15 分;體力跨局延續+局間恢復、
  氣勢跨局歸零、局間 huddle 演出、局間存檔離開(必配)
- 五局制體力曲線獨立治具輪
- 三館制:關鍵戰館+冠軍館程序化建築(共用觀眾/燈光系統)+冠軍館燈光秀開場+
  主客場氛圍(應援音場偏向/橫幅)
- box score:單場結算頁(手機版面)+生涯累積頁+對手 ace 記帳餵情蒐+
  導師觸發規則接數據(縫隙 1 層次二上線)
- 生涯結算(第 3 屆終點):三屆數據定格+關鍵球回放+具名送別+主角畢業儀式+下一章佔位
- 測試:多局制規則(換邊/決勝局)、跨局狀態、box score 記帳決定論

**驗收重點**:冠軍戰五局打滿的完整體驗(館/燈/局間/結算);模擬快進三屆看生涯結算全貌。

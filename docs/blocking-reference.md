# 排球攔網技術拆解：從準備姿勢到起跳（真實排球參考）

> 用途：作為攔網動畫狀態機／AI起跳時機設計的技術參考底稿。
> 範圍：準備 → 讀球 → 腳步移動 → 蹬地起跳（不含觸球後手型與落地）。

---

## 1. 準備姿勢（Ready Position）

- 站位離網保持適當距離，留出側移的蹬地空間
- 雙腳與肩同寬，膝蓋微彎，重心壓在前腳掌，隨時能側向蹬出
- 雙手舉在身前（不是垂在身側）：
  - 能更快把手舉過網高
  - 減少起跳時手碰網犯規的風險

---

## 2. 讀球階段（Reading）

- 眼睛看**攻擊手**，不是看球——攻擊手的助跑線與肩膀轉向是關鍵線索
- 同時預先掌握舉球員習慣、對方主攻的慣用攻擊路線
- 節奏快的球（快攻）：視線必須更早轉向攻擊手，讀球窗口被壓縮
- 節奏慢的球：可以多讀一下舉球員動作再決定，反應時間較寬裕

---

## 3. 腳步移動（Footwork）

依起跳前需要橫移的距離，分成三種模式：

### A. 傳統移動步（Shuffle Step）
- 雙腳平行於網、側向滑步橫移
- 優點：動作單純、雙手全程保持在網前預備位
- 缺點：移動速度慢、覆蓋範圍小、最終起跳高度較低

### B. 交叉步（Crossover Step，2-3步）
- 側跨一步 → 另一腳交叉越過身體前方 → 落地轉正面對網 → 起跳
- 中攔常用 2-3 步交叉步涵蓋較長橫移距離
- 距離不確定時可加入「跳步（hop step）」先找平衡，再垂直起跳

### C. 揮臂式攔網（Swing Blocking）— 目前高水準比賽的主流
- 打開髖部、用動態交叉步移動，起跳前雙臂同步向後擺盪蓄力
- 手臂銜接腳步的節奏：
  1. 第一步：雙手先落到腰部高度（收緊、蓄力、準備狀態）
  2. 第二步：雙臂同時向上擺盪，產生垂直動量
- 相較傳統移動步：起跳更高、跨網手部穿越距離更遠、從A點到B點移動更快
- 近十幾年已從男子排球普及到女子頂級隊伍，現為多數高水準球隊的預設攔網動作

> 傳統移動步的常見錯誤提醒：手臂在舉起過網時**不要向網前甩動**，
> 那個習慣會讓起跳時機更難抓準——這正是揮臂式攔網刻意做「有控制的擺臂」
> 與新手「亂甩手」的本質差異。

---

## 4. 起跳時機（Timing）

- **理想起跳點：攻擊手雙腳離地之後**
- 起跳太早 → 過度出手（over-commit），手已經下降，容易被打穿或落空
- 起跳太晚 → 球從手上方飛過
- 眼睛應在攻擊手起跳前或起跳當下，就已經完成「鎖定攻擊手」的讀球動作

---

## 5. 起跳本身（The Jump）

- 攔網用的是**短蓄力式蹲跳（countermovement jump）**，不是長助跑扣球式起跳
  → 離地速度更快，這也是攔網體能訓練會特別練「短距離爆發垂直彈跳」的原因
- 核心提示：「跳過網，不是跳高」（jump over, not up）
  - 目標是讓雙手**跨越／滲透**到對方場地上空（penetrating the plane）
  - 若手與網帶之間留有空隙，球會被高手「工具球（tool）」打手出界得分
- 起跳到位時的手部姿態（供動畫終點參考）：
  - 肩膀鎖緊上聳（locked shoulder），手臂盡量打直伸過網
  - 手掌張開、拇指與其餘手指略呈45度角，虎口對齊肩寬
  - 手是「牆」，穩定不晃，不做拍擊動作

---

## 供遊戲設計對應參考（可選）

若要對應成攔網動畫／狀態機節點，大致可切成：

```
READY（準備姿勢，雙手前舉）
  → READ（鎖定攻擊手，非球）
  → FOOTWORK（shuffle / crossover / swing，依橫移距離選模式）
  → LOAD（雙臂下擺至腰際蓄力，僅揮臂式攔網有此節點）
  → JUMP（短蓄力蹲跳，起跳時機＝攻擊手離地後）
  → ARM_EXTEND（雙臂打直穿越網面，肩膀鎖緊）
```

其中「起跳時機」與「讀球轉移攻擊手的早晚」兩點，
最適合對應到你們專案已有的 stamina/momentum 節奏系統——
快節奏球（快攻）迫使AI提早鎖定判讀，可以做為攔網AI「誤判/慢半拍」機率的真實依據，
而非單純用隨機數決定攔網成功率。

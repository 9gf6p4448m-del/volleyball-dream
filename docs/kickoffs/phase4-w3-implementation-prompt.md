## 3. S 分配決策玩法

- 範式:沿 attackZones.js+zonePanel 決策點架構(sim 決策點暫停語意 → UI 面板 → Intent 注入,Intent 唯一輸入不變)。
- 決策點:我方一傳起球後,時間放慢,面板列出**一傳品質分支下的合法選項池**(到位=全池含快攻/可用=無快攻/勉強=兩翼高球——現行機制,消費方向反轉:由玩家選而非 trust 權重抽)。
- **trust 反轉(甲2 拍板 C)**:
  - 隊友 trust 極低(門檻值實作時初擬,治具驗邊界)→ 該隊友快攻選項面板變暗+標「猶豫」,**可選但有標註**(顯示哲學:狀態誠實呈現);配助跑遲疑動畫。

  - trustFloor 0.27 對轉 S 玩家停用(保底對象語意消失)。
  - trust 升降動態(trust.js)照舊:隊友被你舉且成功=升,連續失誤=降——玩家親手經營。
- 建隊鏈:玩家佔 S 槽=careerTeams 硬編 A2/index1 守衛(careerState.js:339)必須參數化——**地基級,Fable 深推理**;SLOT_ROLES 5-1 對位、defaultStarters 佇列同鏈調整;阿哲讓位轉副手(縫隙 1 層次二,見 §6)。

# 附錄 A|L(自由人)玩法設計定案(2026-07-27 半場設計討論,Sawmah 逐題拍板)

## A1. 核心決策點:雙層合一(C 案)

- 決策點=**對手舉球出手瞬間**,時間放慢,選後排收縮方向:**守直線/守斜線/守吊球**。
- 整個後排陣型跟著移動(dig 收縮 AI 吃玩家指令),玩家自己的站位是陣型的一部分自動帶動。
- **讀對且球飛向玩家=Perfect 接球時機窗主動觸發**(Phase 1 既有機制首次由玩家主動開啟)。
- 設計語意:與視線欺敵成鏡像——OH 時代騙攔網,L 時代反讀攻擊手。

## A2. 節奏:預設快選+可跳過(C 案)

- 每次對手進攻放慢 **0.6×**(比 OH 攻擊 0.4× 短)。
- 面板**預設高亮 AI 建議選項**(現行防守 AI 判斷);玩家不動=**1 秒後自動照建議執行**;點選=改判。
- 改判成功起球=專屬演出點(見 A4①)。
- 「AI 建議 vs 改判」結構預留給導師對話與數據文化(改判成功率)消費。

## A3. 規則特例資產化(三條全採)

1. **不可攻擊 → 送球的藝術**:玩家起球品質直接驅動一傳品質戰術分支(Perfect=全池含快攻/可用=無快攻/勉強=兩翼高球)——既有機制,首次由玩家手感驅動。得分鏡頭給扣球者,**起球記「助攻一傳」**(記帳進 sim 事件流)。
2. **不可到前排 → 輪轉即節奏**:前排三輪玩家在場邊=**縮時教練視角**(沿 W7 板凳「純教練視角」架構縮時版),觀察對手攻擊 → 產出**「習慣標記」**(如「此攻擊手偏斜線」),下次上場時顯示於防守面板。標記生成=決定論(讀 sim 事件流統計,非隨機)。
3. **替換自由 → 儀式**:applyLiberoSwaps 自動執行照舊,配輕演出(異色球衣入場+與被換者擊掌);非決策、純節奏儀式。

## A4. 表現層(四條全採;①②③=W3,④=W4)

1. **魚躍救球=L 的重扣慢動作**:改判成功或 Perfect 窗撲到必死球 → 慢動作+**低機位貼地鏡頭**(球與指尖距離)+塵土+觀眾倒抽氣後爆歡呼。鏡頭語言與 OH 反向:OH 俯衝向下,L 貼地仰起。
2. **rally 延長=L 的計分板**:神救球續命 rally=觀眾聲浪疊層(既有長 rally 機制強化);rally 由我方終結時,鏡頭先給扣球者、再切玩家握拳。
3. **隊友回饋**:神救球後隊友擊掌/拍頭動畫;當屆 S 專屬台詞(「有你在後面,我敢舉快攻」)——把 A3① 機制翻譯成人話。
4. **box score L 三欄**(W4 落地,W3 立契約):起球數/助攻一傳/rally 續命數。

## A5. 平衡與治具

## 六、硬性約束（設計時不得違反）

- `src/sim/` 純核心：零 three.js／DOM、固定步長 60Hz、**決定論**、**不得認識「屆數／生涯」**
  （已有 `SEASON-SCAN` 靜態掃描釘死）
- **憲法 §九**：**球內**不得新增任何決策面板（死球窗與既有面板不在此限——§九-A 已明示收窄）
- **憲法 §十一 自由度紅線**：**給資訊、他自己跑**，不得為受控玩家自動走助跑線
- **§0 題5**：OH **球內**要球機制維持不做（死球窗的請求已由 §九-A 收窄出來）
- **誘餌維持湧現式**：sim 不得新增誘餌旗標（`COMBO-SCAN` 靜態掃描釘死）
- **反作弊**：AI 的內部計畫（`blockPlan`）不得洩漏給玩家；回饋只能從可觀察結果導出
- **反滾雪球**：不得在強勢位置疊信任加成（OH 要球鈕就是因此被否決）
- 平衡熔斷：主判 |Δ奪冠| ≤15pp／加掛主判 |Δ決賽| ≤15pp／輔助「任一輪 |Δ|>25pp」，**RUNS ≥ 100**

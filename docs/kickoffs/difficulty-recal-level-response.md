## 四、換算率結論

**對手 level 每 +1 ⇒ 奪冠率約 −2.5～−3 pp（絕對百分點），但這條換算率只在 delta ∈
[−2, +2]（奪冠率落在 2%–13% 這段、還沒探底）有效**：

- −2 → 0：13% → 8%，−5pp / 2 級 = **−2.5pp/級**
- 0 → +2：8% → 2%，−6pp / 2 級 = **−3.0pp/級**
- 兩段內部一致，取平均 **≈ −2.75pp/級**，可當「基準難度附近」的操作換算率
  （例：要把奪冠率從 8% 壓到 5% 附近，約需 +1 level；要壓到 12%–13%，約需 −2 level）。

**delta ≥ +4 之後進入地板效應**：奪冠率 1%、0%、1%（+4/+6/+8）彼此都落在 Δ 的配對 SE
（±2.7–2.9pp）之內，統計上分不出來——**繼續加 level 對「奪冠率」這個指標已經測不出額外
效果**，因為奪冠率本身已經逼近 0% 的下限，不是換算率變小了，是這個指標本身沒有更多空間
可以下降。若要壓更低的難度目標（例如奪冠率 <5%），level 旋鈕在這個範圍內綽綽有餘
（+2 就已經壓到 2%）；但若需要區分「level+4 vs level+8 誰更難」，奪冠率這個指標在此區間
已經飽和、不具鑑別力，得換別的指標（例如六場勝率或分差）。

## 四之二、★ 這條換算率**不能外推到第 2、3 屆** ★（主對話補，2026-08-03）

本輪是**單屆**量測，基準奪冠率 **8%**。而難度重校真正要解決的是**第 2、3 屆**
（現況 **17%／35%**，見 `difficulty-recal-discussion-brief.md` §七）——
那個區間**離地板還很遠**，level 的邊際效果與這裡量到的不會是同一個數。

⇒ **要校二三屆，必須在二三屆的區間重量一次**（`VD_SEASONS=3` ＋ `VD_LEVEL_DELTA`）。
把本表的 −2.75pp/級 直接套到二三屆會**低估所需幅度**（本表的斜率是在「已經快撞地板」的
區間量的，那裡每一級的邊際效果被壓縮了）。

## 四之三、★ 送裁：錨 3a 用奪冠率當標的，可能驗不出達標 ★（主對話補，2026-08-03）

錨 3a 要的是奪冠率 **6 → 9 → 12**。但把本檔的量測精度端出來對照：

2. **把錨改寫在解析力更好的指標上**——本檔量到 **決賽帶**（46/38/30/17/11/10）

## 五、線性 / 非線性判定

**非線性，拐點約在 delta=+2 到 +4 之間**（奪冠率響應）：

- delta ∈ [−2, +2]：接近線性，斜率穩定在 −2.5～−3.0pp/級。
- delta ≥ +4：奪冠率已探底（0%–1%），響應曲線攤平，不再有可辨識的斜率
  （三點 1%/0%/1% 彼此在雜訊帶內）。

**六場逐場響應則呈現不同的飽和模式，各場不一致，不能套同一條線**：

- **national-final**（宿敵天鷹，基準勝率就只有 23%）對 level 最敏感也最早見底：
  +6 時已壓到 3%，但 +8 卻回彈到 10%——這一跳落在 ±5pp 雜訊帶內（Δfinal 在
  +6／+8 兩臂的 SE 分別 ±4.5／±5.1pp），**判定為樣本雜訊、非真實回升**，不代表
  level 越高玩家在決賽反而更容易贏。
- **national-qf／national-sf** 在 +4 之後也出現類似的平台（qf：22%→18%→19%；
  sf：69%→56%→56%），同樣落在雜訊帶內，判定為飽和而非精確的階梯。
- **group-1/2/3**（小組賽，基準勝率 83–86%，離地板還遠）在整段 −2 到 +8 都維持
  單調下降、沒有明顯飽和跡象（+8 時仍有 53–57%），**這三場的響應目前看起來比奪冠率
  更接近線性、更適合拿來做精細調校的指標**（如果重校目標是「小組賽該多難」而非
  「奪冠率」）。

**結論**：奪冠率換算率（−2.5～−3pp/級）只在 delta∈[−2,+2] 這個「基準難度附近」的區間
可用；往上調更大的 level 位移前，若目標仍是壓低奪冠率，效果會迅速鈍化，該用六場勝率
（尤其小組賽三場）當調校指標，而不是死盯已經探底的奪冠率。

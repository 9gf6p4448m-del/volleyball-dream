## D1 謝幕卡內容（資料吃 career.seasons）

- 逐**職業**年一列：章內第 N 年、隊名（pro id 解析）、循環名次（proRank）、
  季後賽標籤（proFinish 四態：冠軍/亞軍/四強/未進）、年薪（salary；舊檔缺值
  ＝proBaseSalaryFor(該隊) 回退——批 2 掛帳裁定）。
- 合計列：職業年數、冠軍數（proFinish==='champion' 計數）、職業總勝敗。
- 非職業封存（高中/大學/企業）不出現在謝幕卡（生涯數據頁已有全史）。
- 什麼實作會紅：冠軍數拿 proRank===1 算；舊檔缺 salary 顯示 undefined；把大學季
  也列進來。

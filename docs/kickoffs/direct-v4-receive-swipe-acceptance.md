# direct-v4 接球滑動平台角度：驗收條件（2026-09-24 動手前凍結）

使用者裁定（全部照建議）：①四向離散，同扣球手勢 ②上＝高球到位、下＝低平安全球、左右＝偏左偏右、不滑＝平台正對身體 ③觸球窗口開始即鎖定 ④入門＋標準顯示平台朝向線與接球時機提示，進階不顯示；提示不改判定 ⑤訓練新增「接球方向練習」，地上標目標區，只顯示結果、不保底。

本檔凍結後，任何會讓通過機率上升的修改（降門檻、縮案例、改量測方式）須先寫明原標準錯在哪，並取得使用者對該條的明確同意。

## 模擬核心（`src/sim/`，決定論）

- **A1 指令契約**：指令欄位 `passType` 的值只能是 `HIGH`／`LOW`／`LEFT`／`RIGHT`／`NEUTRAL`。只在「同 tick 開始墊球」或「墊球準備期（actionTick < windup）」時採用；其他時候（出手窗口後、非墊球動作、非法值）一律忽略。按下墊球沒帶 `passType` 就是 `NEUTRAL`。單元測試逐條驗。
- **A2 連續與鎖定**：平台角度在準備期連續過渡，每個 substep 的角度變化 ≤ 設定速率；從出手窗口第一個 tick 到動作結束，平台角度逐值不變（測試逐 substep 取樣）。
- **A3 物理效果（真實鏈路）**：用正式 `feed(receive)`，玩家站在固定位置，只改 `passType`，同一按鍵時機，每種都要產生主動（active）的前臂或手部觸球。量測觸球後的球速或弧頂：
  - LEFT 的出球 vx ≤ NEUTRAL 的 vx − 0.5 m/s（往玩家左側，也就是 −x；玩家面向 −z）；RIGHT 的 vx ≥ NEUTRAL + 0.5 m/s。
  - HIGH 觸球後弧頂 ≥ NEUTRAL 弧頂 + 0.3 m；LOW 觸球後弧頂 ≤ NEUTRAL 弧頂 − 0.3 m。
  - 以上須在至少 3 個站位（x = −0.3、0、0.3）都成立。
- **A4 不放大、不傳送**：各 `passType` 的姿勢，膠囊數量、半徑、active 旗標都和 NEUTRAL 相同；球速只在碰撞時改變。同一球若沒有碰到身體，不論選哪種 `passType`，整段軌跡都和 NEUTRAL 逐位元相同。
- **A5 決定論**：含 `passType` 的錄影，整卷重播與逐 tick 還原都逐位元相同；`direct-v3` 錄影明確拒絕。
- **A6 不加衝量**：出手窗口內，平台角度的變化對表面速度的貢獻為 0（由 A2 的鎖定保證，另加一條測試：晚到準備期最後一個 tick 才選，觸球後球速與「準備期結束時角度」一致，不含轉角速度）。

## 輸入

- **A7 手勢**：觸控出手鈕在墊球時滑動會送出對應的 `passType`（分類規則與扣球四向同一套方向判定：上、下、左、右、不滑）；原本的左右滑改朝向行為保留。鍵盤墊球送出 `NEUTRAL`。有自動化測試（沿用既有輸入測試的方式）。

## 畫面與訓練

- **A8 平台朝向線**：入門與標準模式在墊球準備期與出手期顯示；進階不顯示。朝向線由共享姿勢的前臂計算，不另算物理。
- **A9 時機提示**：入門與標準模式在墊球可觸及的來球接近時，出手鈕外圈收縮；進階不顯示。只有畫面，不改任何模擬輸入。
- **A10 接球方向練習**：餵球選單新增「接球方向練習」，使用正式墊球餵球（模擬核心不新增分支），地上標示目標區；球落地後顯示命中，或落點相對目標的偏移（公尺）。不改變球的任何速度與位置。
- 以上 A8–A10 由瀏覽器治具在 1280×720、844×390、390×844 三種尺寸驗證（DOM 或場景物件的可見性斷言＋截圖），無 console error／pageerror。

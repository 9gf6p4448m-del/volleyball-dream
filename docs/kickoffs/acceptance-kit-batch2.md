## N2 背號決定論、不動存檔
- 場上每名球員（雙方各 6＋自由人）背面有大號、胸前有小號。
- 號碼由決定論函式推導（同一名冊/對手 def 任兩次進場同號；單測：呼叫兩次結果相同）。
- 同隊場上不得撞號（單測：14 人場景兩隊各自號碼唯一）。
- 存檔 schema（`career/schema.js` 驗證器）零改動（git diff 為證）。

## N3 背號可讀性（機械斷言）
號碼顏色由函式依球衣底色自動選擇，對 16 隊全部球衣色與自由人色、
以及預設 TEAM_KIT/LIBERO_KIT 的 A/B 面：號碼色 vs 底色 redmean **≥ 150**。
進 node 測試永久守門。
★鑑別力：對「號碼色恆白」的壞實作，深底可過、淺底（如 0xf2f4f8 白衣隊）
必須被此斷言抓紅★

## N4 trim 色實際上身＋效能邊界
- trim 幾何件（領圈/袖口/側條擇二以上）以 kit `trim` 色上到球員模型，
  走 InstancedMesh 池（per-instance color），新增池數 ≤ 4（單測斷言池清單）。
- 背號面片全場新增 mesh ≤ 30 個（14 人×前後 2 面）（單測斷言數量上限）。
- 貼圖快取：同號碼＋同色只建一份 CanvasTexture（單測：兩次取用回同一實例）。

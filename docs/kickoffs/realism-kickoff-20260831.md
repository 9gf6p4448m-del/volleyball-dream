## 批4 撤案記錄（2026-08-31，R4-2 量測程序的產物）

配對同種子 60+60 局（scratchpad `commit-shift-probe.mjs`）：**commit 牆比 read 牆弱**——
攻方對 commit 牆拿局率 43/60 vs 對 read 牆 33/60；quick|middle 86.5→91.2%、
left|cross 77.8→95.5%。成因：①commit 賭注按二傳配分權重抽（08-01 裁定），~80% 沒賭在
快攻手身上＝準時跳在沒球的地方 ②批5 的 MB 分工縫只修了 read 人格。
⇒「強隊改 commit＝更會擋快攻」的前提**不成立**，照原計畫執行會把強隊變好打。
批4 撤案不執行；曜石/鐵骨/極光等既有 commit 隊 DNA 維持 08-01 裁定原樣。
若未來要讓 commit 真的強起來（賭注收斂或 commit 版分工縫），屬攔網時序憲法區，另卷另裁。

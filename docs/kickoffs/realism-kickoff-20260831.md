## 批4 撤案記錄（2026-08-31，R4-2 量測程序的產物）

配對同種子 60+60 局（scratchpad `commit-shift-probe.mjs`）：**commit 牆比 read 牆弱**——
攻方對 commit 牆拿局率 43/60 vs 對 read 牆 33/60；quick|middle 86.5→91.2%、
left|cross 77.8→95.5%。成因：①commit 賭注按二傳配分權重抽（08-01 裁定），~80% 沒賭在
快攻手身上＝準時跳在沒球的地方 ②批5 的 MB 分工縫只修了 read 人格。
⇒「強隊改 commit＝更會擋快攻」的前提**不成立**，照原計畫執行會把強隊變好打。
批4 撤案不執行；曜石/鐵骨/極光等既有 commit 隊 DNA 維持 08-01 裁定原樣。

## 壓手語意重定（08-31 Sawmah 討論定案；推翻 08-24「正面當成本」）

Sawmah 兩個修正：①正面與手頂都該是壓手優勢（手面朝下＝球被折進對方場內）
②壓手的真實弱點不是被打手，是被瞄「手與網帶之間的縫隙」鑽進去——台灣排球俗名
**「吞下去」**（國際上預防端叫 sealing the net）。定案模型：
- 優勢＝擦頂壓死（既有）＋正面攔死加成（BLOCK_PRESS_BODY_MUL 0.85→**1.2**）
- 代價＝觸網（既有 0.12）＋**吞下去低窗**（PRESS_SEAL_GAP 0.15：網高之上此高度內的
  過網球對壓手成員是穿透；直臂不受影響）
- 「擦側=打手」稅退役（SIDE_MUL→1.0）：打手瞄的是任何牆的外緣，非壓手專屬
- 平衡判準修訂：接觸後 EV 允許小幅為正——壓手綁封線承諾（接觸前已付賭錯線的稅），
  08-24「接觸後 EV≈0」漏了這筆。配對重演（press-gap-sweep 變體 1907 點）：
  全樣本 +2.0±3.1（雜訊內）、top +25.3 顯著；GAP 0.20 實測 −8.2 顯著＝過兇已否決。

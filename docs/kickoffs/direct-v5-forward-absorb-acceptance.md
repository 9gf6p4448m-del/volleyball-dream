# direct-v5 墊球吸收往前的身體速度：驗收條件（2026-09-25 動手前凍結）

使用者裁定（2026-09-25，方案甲）：主動墊球觸球時，接觸面速度扣掉玩家身體水平速度中「往網子方向（−z）」的分量；橫移與後退的身體速度照舊傳到球上。背景是 direct-v4 第四輪覆審的 M-B：往前或斜前移動中觸球，碰網率 84–91%。

動手前探針（scratchpad worktree，把接觸面速度扣掉 k 倍身體水平速度；k=0 就是現況）：往前、速度 0.5–1.5 m/s 時碰網 83%／52%／0%／0%（k = 0／0.5／0.75／1）；速度 > 1.5 m/s、k=0 時球越過網子，舉球區 0%。只吸收往前分量的版本和 k=1 的結果相同。

本檔凍結後，任何會讓通過機率上升的修改（降門檻、縮案例、改量測方式）須先寫明原標準錯在哪，並取得使用者對該條的明確同意。

## 模擬核心（`src/sim/`，決定論）

- **A18a 往前移動中接球**：正式墊球餵球（`feed`），起點 x0 ∈ {−0.3, 0, 0.3} × z0 ∈ {5.4, 5.8, 6.2}；從第 10 tick 起搖桿 (0, −m)，m ∈ {0.2, 0.35, 0.5, 0.8, 1.0}，直到球結束都不放開；按墊球時機為第 18–40 tick，不滑（NEUTRAL），朝向正對球網。只計主動前臂或手觸球、且觸球當下身體水平速度 ≥ 0.05 m/s 的案例，須 ≥ 100 例。結果以球第一次結束（ground／net／out）判定。門檻：
  - 全體：碰網率 ≤ 10%；落在舉球區（地面，z 0.5–3 m，|x| ≤ 3 m）≥ 50%。
  - 按觸球時身體速度分成 0.5–1.5 m/s 與 ≥ 1.5 m/s 兩組，各須 ≥ 30 例，且各自碰網率 ≤ 10%、舉球區 ≥ 50%。
- **A18b 斜前移動中接球**：同 A18a，但搖桿為 (±0.7m, −0.7m)，左右兩個方向都跑。門檻：全體碰網率 ≤ 10%、舉球區 ≥ 50%；兩組速度各自碰網率 ≤ 10%。
- **A18c 只吸收往前分量**（區分方案甲與「全部吸收」）：用 `collideBody` 直接驗證。兩條主動前臂組成一個朝上、朝網子傾斜的平台，另一種是法線有左右分量的平台；玩家在墊球動作中，平台以玩家速度平移，`player.vx`／`player.vz` 與平移一致，速度 1.5 m/s。
  - 往前平移（−z）：觸球後球速與「平台靜止」的差 < 0.05 m/s。
  - 後退平移（+z）：觸球後球速與「平台靜止」的差 ≥ 0.3 m/s。
  - 橫向平移（法線有左右分量的平台）：觸球後球速與「平台靜止」的差 ≥ 0.3 m/s。
- **A18d 版本**：`SIMULATION_VERSION` 升為 `direct-v5`；`direct-v4` 錄影明確拒絕。既有測試與瀏覽器治具中的版本字串跟著升版改（這是升版的必然結果，先例 da5cf36／91d7d93），v4 拒絕的斷言取代原本 v3 拒絕的斷言。

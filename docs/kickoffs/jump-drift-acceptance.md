# 跳躍前飄（渲染層）驗收條件——凍結於本 commit

起點：feat/real-match 55cc61b（線上 gh-pages 17b35b7）。分支 feat/jump-drift。

## 問題
使用者 09-28 手機試玩：FPS 常駐 60（B11 過），但扣球等跳躍「垂直起跳，不自然」。
根因：sim 起跳點刻意退在擊球點後方（src/sim/approach.js:110-114 TAKEOFF，註解意圖＝空中前飄），
但 SETTLE 到位即停、原地拔起；渲染層跳躍弧只寫 Y（src/render/geoAnimator.js:791），
root 水平只吃魚躍與 reachAssist（src/render/matchView.js:538）。前飄從未被畫出。

## 使用者裁定（09-28，四題皆照建議）
1. 範圍：扣球（前排）＋後排攻擊（pipe/dball）＋跳發 加前飄；攔網維持垂直；跳舉僅微量（≤0.15 m）。
2. 距離：飄到擊球點（sim 起跳點→擊球點實際水平距離），且不得過網。
3. 落地：落地緩衝幀先停在前方，之後約 0.4 s 平滑併回 sim 位置。不改 sim。
4. 對象：AI 與玩家操控（v8 直接操作）都要生效。

## 驗收（每條註明「什麼樣的實作會讓它變紅」）
- J1 sim 不動：tools/sim-hash-probe.mjs 對 sim-hash-baseline.json 全相同；src/sim/** 無 diff；npm test 全綠（基準 2613/2613）。
  紅：動了 sim 或任何判定。
- J2 前飄存在：新量測腳本走真實 matchView/animator 鏈路（不重抄公式），對 ≥3 個種子的正式比賽取所有扣球／後排攻擊／跳發，
  量「起跳幀→擊球幀」root 沿助跑方向水平位移 d_render，與 sim 起跳點→擊球點水平距離 d_sim 比：
  每一筆 d_render ≥ 0.8·d_sim（過網截斷者改驗 = 截斷值±0.02 m 並列出）；每類樣本數 ≥5，並回報各類筆數。
  修前基準也要跑一次並貼數字（預期 ≈0，證明探針會紅）。紅：沒做前飄或只做一半。
- J3 空中平順：滯空期間 root 沿前進方向位移單調不減；任一幀水平步長 ≤0.05 m（60fps）。紅：瞬移、倒退、抖動。
- J4 手球落差不惡化：擊球幀擊球手到球心距離，改後中位數 ≤ 改前中位數、改後最大值 ≤ 改前最大值＋0.02 m（兩組數字都貼）。
  紅：前飄方向或距離錯，把手帶離球。
- J5 不過網：所有樣本全幀 root 與網面水平距離 ≥0.15 m 且在己方側。紅：前排飄過網。
- J6 攔網不變、跳舉微量：block/blockJump 全幀前飄偏移恆 0（完全相等）；跳舉偏移 ≤0.15 m。紅：範圍外的跳躍被改動。
- J7 落地併回：落地後 ≤0.5 s 內 render 與 sim 水平位置差 <0.01 m；併回期間每幀步長 ≤0.05 m；無一幀瞬移。紅：落地瞬間彈回起跳點。
- J8 直接操作模式：v8 直接操作的玩家扣球與跳發同樣過 J2/J3/J5/J7（治具或腳本在 direct 模式下量，各 ≥3 筆）。紅：只對 AI 生效。
- J9 既有條件回歸：2A B1–B12/H1（含 B12 截圖重跑）、2B E2(a)/E3/E4/E5/DA2、v8 四治具、R8 維持原值。紅：打壞既有外觀或動作。
- J10 使用者手機試玩判定自然度（最終權威，不由任何機械條件替代）；FPS 仍需平均≥59。

## 修訂紀錄
任何讓通過機率上升的修改須先寫明原標準錯在哪，並取得使用者對該條的明確同意。

- R1（09-28，使用者同意「同意放寬到 0.07」）：J3 與 J7 的每幀水平步長上限 0.05 m → **0.07 m**。
  原標準錯在：0.05 m／幀＝3 m/s，低於 sim 攻擊手起跳當下的助跑速度（約 3.3 m/s）與真人 3–4 m/s；訂條件時沒先量 sim 跑速。
  現在才知道：改前量測（daa7004）＋ tools/jump-drift-feasibility.mjs 證明 183 筆中 77 筆無論實作都無法同時過 J2/J7 與 J3。
  其餘（J2 的 0.8·d_sim 以起跳幀 P0 起算、J7 的 0.5 s、J3 單調不減）一字不改。
- R2（09-28，使用者同意「移到第2階段扣球卷」）：J8 原文移出本卷——直接操作模式不經 matchView（src/app/directPractice.js:6 用 directPlayerView，起跳為 directGame 物理），且該模式無玩家發球，原條件恆假。
  該模式的空中前飄併入 direct-v8 第 2 階段扣球卷。**J8 改為**：正式比賽中玩家所屬球員（A2）的扣球樣本單列 ≥3 筆，逐筆過 J2/J3/J5/J7。
- R3（09-28，自行修正事後回報：原條件恆真）：跳發的 sim 擊球點在發球者腳下，d_sim＝0，J2「≥0.8·d_sim」恆真。
  **改為（加嚴）**：跳發起跳幀→落地幀 root 沿發球方向往場內位移 0.6–1.5 m，且過 J3/J7。

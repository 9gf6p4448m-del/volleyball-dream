# 墊球恢復「按下即出手」：驗收條件（2026-09-25 動手前凍結）

使用者裁定（2026-09-25，方案 1）：觸控墊球恢復 direct-v4 的「按下即出手」，按下後在準備期內左右滑選平台方向。取代 A19「按住預選、放開出手」。

原因（實測，線上 direct-v5、390×844、金色共 11 個 tick）：在金色時點下出手鈕、手指停留 0／3／6／9 tick 才放開，球彈得起來的比例分別是 11／8／5／2（/11）。一般人點一下約停 6 tick，放開才出手等於把墊球延後，手臂還沒進入主動觸球，球就先打到。A19 的測試都用同一瞬間按下放開，量不到這個問題。

範圍：只動輸入層、畫面文案與測試；模擬核心不動（`SIMULATION_VERSION` 維持 `direct-v5`）。往前吸收（A18）、接球自動轉身三模式（A20）、金色預演帶入朝向，全部保留。

本檔凍結後，任何會讓通過機率上升的修改（降門檻、縮案例、改量測方式）須先寫明原標準錯在哪，並取得使用者對該條的明確同意。

## 驗收條件

- **A21a 按下即出手**：選墊球時，出手鈕 `pointerdown` 當下取樣即為 `[null, 'receive']`，`passType` 為 `NEUTRAL`；之後左右滑送出 `LEFT`／`RIGHT`（不重新觸發動作、不改朝向）；`pointerup` 不重送。
- **A21b 真人點擊停留時間**（瀏覽器原生觸控，`--pass` 治具，三種尺寸）：入門模式、正式墊球餵球、玩家不動；在每一個金色 tick 按下，手指停 0／3／6／9 tick 才放開。每一種停留時間，球被主動前臂或手觸到、且觸球後球的最高點 > 2 m 的比例都要 ≥ 10/11（以實際金色 tick 數為分母）。
- **A21c 方向指示**：按住期間出手鈕仍顯示目前的平台方向（`data-pass-choice`），文案改為不含「放開」的「正前／偏左／偏右」；放開或取消後移除。時機圈（`::after`）與方向標籤（`::before`）同時可見的檢查保留。
- **A21d 文案**：提示與結果訊息恢復「按墊球」的語意（例如「提早按墊球」「早一點按墊球」），不再出現「放開＝墊球」。
- **A21e** 既有測試：`tests/direct-pass.test.js` 的 A7、A3b 恢復成 direct-v4 的內容（`91d7d93`）；`tests/direct-hold-release.test.js` 的 A19a／b／c／e／f 依使用者裁定退場，改寫成 A21a／A21c 的測試；A19d 的「扣球按下即出手」、lostpointercapture、heldPassType 的測試保留。
- **A21f** `npm test` 全綠、`npm run build` 成功；瀏覽器治具預設／`--assist`／`--motion`／`--pass` 全部 PASS；`git diff` 中 `src/sim/` 零改動。
- **A21g 鑑別力**：A21a 與 A21b 的 6／9 tick 在目前（A19）的程式碼上必須紅。

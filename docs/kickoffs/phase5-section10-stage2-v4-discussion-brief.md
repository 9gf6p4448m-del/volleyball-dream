### 2.1 為什麼過網 tick 不可導

「解不出值」與「解出來的值錯」是兩件事，本輪分開量了：

- 幾何上有正解的比例 **67.9%**。只看這個數字會誤判成「大致可導」。
- 但**解出來的值誤差 p50 117／280 tick**。後排 **0/57** 連正解都沒有。

**⚠ 以下是解釋，不是量測結果**（但與量測一致）：取樣那一刻球還在**二傳的球路**上。
那組速度描述的是「二傳的球慢慢飄過網」——而球會**先被攻擊手扣走、換上一組全新速度**
才真的過網。**取樣時那組速度，和真正過網的那組速度，是兩件不同的事。**

⇒ 不是「精度不夠、多量幾局會好」，是**結構性的**。

### 2.2 為什麼擊球 tick 可導而且很準

**⚠ 機制描述，未經獨立量測**：擊球點的預測走的是球**自己的**拋物線墜到「扣球窗上緣」
這個高度的那一刻——這件事在取樣時就已經完全決定了（球已離二傳的手），不需要知道任何人的意圖。

**實測**：誤差 sd **0.48–0.76 tick**、全距 ≤3。

（快攻有 **+8 tick** 的系統偏晚，兩翼／後排只有 +1。這個偏晚在 §4.3 會變成關鍵。）

### 2.3 補差位移不是常數（R2 已預先禁止的那條）

R2 原文：若過網 tick 不可導，**不得用固定位移補差**，因為該位移為 quick 6／wing 7／back 18，**不是常數**。

本輪補齊離散度，結論比裁定書設想的更強：**組間**不是常數（6／7／18），
**組內也不是**（sd 4.8–7.7，全距 3–24／3–21／16–41）。⇒ **R2 的紅線成立。**

### 4.0 先解一個看起來像矛盾的地方

第二次冷讀指出：「快攻／前置 0」報 p50 **81.4%** 而「離開地板」只有 **21.1%**，
若 79% 的樣本都在地板上，中位數就該**等於**地板值 81.2%，兩者不可能同時對。

**查證結果：不是矛盾。** 地板是**逐球員值**，這一組量到 **2 種取值**（81.2% 與 81.4%）。
79% 的樣本各自貼在**自己的**地板上，那些地板值的中位數是 81.4% ⇒ 完成度的 p50 落在 81.4%。
探針現已加印地板的 p10/p50/p90 與相異取值數，讓這件事不必再靠推理。

### 4.1 讀法（對照 §3.1 的三款）

- **前置 0**：快攻離開地板 **21.1%**（≪ commit 的 55.9%）⇒ **款 3 成立，賭局回來**；
  兩翼 **100.0%**、後排 **77.2%** ⇒ **款 1 成立**；commit 不動（R3）⇒ 款 2 維持 ✅
  **三款全成立。**
- **前置 12**（R2 原形式）：後排離開地板 **0.0%** ⇒ 款 1 全失守；快攻 96.5% ⇒ 款 3 壞更徹底。
- **前置＝反應延遲**：後排 **0.0%** ⇒ 款 1 失守；快攻 87.7% ⇒ 款 3 不成立。**出局。**
- **前置 8／6**：後排只有 17.5%／63.2%、快攻 100%／96.5% ⇒ 款 3 不成立。且**需新導出常數**。**出局。**

⇒ **五個候選裡，前置 0 是唯一讓三款同時成立的，而且它零新常數。**

### 4.2 但它不符合 R2 寫的「目標」——這是要裁的核心

R2 的目標是「**跳躍頂點對齊球抵達網面**」。**⚠ 以下含機制推算**：前置 0 下頂點落在
「擊球 + 半窗」，而球過網在「擊球 + 6／7／18」⇒ **頂點從來沒有對齊網面**：
球過網時手還在上升（兩翼）或已在下降（後排），快攻則多半還沒離地。

**所以 R2 的「目標」與 R4 的「驗收」在球的實際幾何下不能同時成立**：
- 要「頂點對齊網面」⇒ 需要過網 tick ⇒ **不可導**
- 退到最近的可導錨點（擊球 tick）＋前置 12 ⇒ **後排死在地板、快攻被打穿**
- 前置 0 ⇒ 不對齊任何頂點，但**六格結果完全符合 R4 三款**

### 4.3 為什麼前置 0 對快攻剛好來不及，以及這件事有多脆弱

**⚠ 以下是由 §二 兩列數字導出的判準，不是獨立量測。**

前置 0 下，read 只在「**飛行段 > 預測偏晚**」時來得及離地。
快攻的偏晚是 **7–9**（sd 0.76，很緊），飛行段 p50 **6**、全距 3–24
⇒ 只有飛行段偏長的那些球會離地，實測就是那 **21.1%**。

**這正是 v3 裁定書 §5.1-1b 說「想不出來」的那個代價**：read 對快攻的結構性劣勢不靠加罰、
不靠新常數，而是**球對快攻的擊球點本來就比較難預測得早**。

**但它的餘裕只有約 4 tick（≈67 ms）**：偏晚若從 8 降到 4 左右，快攻就會大幅離開地板、
**款 3 再次翻轉**。⇒ **任何日後改善擊球點預測精度的改動都會打穿款 3。**

⇒ 所以 §5.1 的工作項必須包含**一條把這個偏晚釘住的測試**，否則這是一個等著回歸的陷阱。
（這一項是第二次冷讀指出來的，第二版沒寫。）

### 4.4 前置 0 會不會又回到十-2 譴責的「對扣球事件零延遲反應」？

**機制層：不是。** 前置 0 讀的是**二傳出手後球的拋物線**，在「二傳觸球＋反應延遲」那一刻
取樣**並鎖存**，早了 50–80 tick、之後不重算；舊行為讀的是「**扣球已經發生**」這個事件本身。
**R1（取樣時點＋鎖存）是這條區別的唯一載體**，且可以被測試釘住。

**觀感層：本檔無法自證，但有一項有利事實。** 若十-2 譴責的是**觀感**
（攔網手在扣球瞬間拔起看起來像作弊），那資訊來源救不了觀感。
不過前置 0 下，球過網時兩翼的手**還在上升**、後排**已在下降**、快攻多半**還沒離地**
⇒ 動作看起來**偏晚**，與舊行為「球一出手就準時拔起」的觀感簽章不同。

**⚠ 本檔不引用 v3 裁定書 §二 的結論當論證**（那對只有文字的裁定端是循環引用）。
若十-2 的原意包含觀感，請直接裁定，實作端不自行認定。

## 七、附帶新事實：冷讀 §乙 的和解，載體與裁定書設想的不同

v3 裁定書 §乙 判定 commit×快攻 是**巧合過關**，推得的機制是「誘餌下降沿 p50 set+32

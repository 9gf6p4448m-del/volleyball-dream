## 1. 宿敵三幕——莊敬嶺「攀天者」（本輪核心）

人設全文＝W4 快照 §7 案 B（已落檔 opponents.js sky-hawk ace、grade 1、rival 豁免）。
核心：曾在牆的另一邊，爬過來之後把牆砌得更高。「我證明過了。爬不上來，是你不夠想。」

### 1-1 掛點與硬保底（拍板 A）

- **幕一＝第 1 屆首遇天鷹**：賽程生成時保證天鷹出現在玩家第 1 屆賽程（小組或關鍵戰皆可，首遇場即幕一）。
- **幕二＝第 2 屆準決賽**：保證天鷹在準決賽等玩家（玩家打進準決賽即撞上）。
- **幕三＝第 3 屆決賽**：同理保證。
- 保底＝**賽程生成內的種子決定論約束**，不是事後補場；同種子同賽程鐵律不破。
- **止步降級版（A 的必要配套）**：玩家該屆未打進對應輪次 → 該幕改掛「屆末旁觀播報版」——場邊看他奪冠，旁觀視角短版台詞另寫，三幕鏈不斷。呼應人設：你爬不上去的那年，他還在牆頂。

### 1-2 幕次內容與勝負分版（拍板 A）

三幕結構恆定，僅賽後對話分勝/敗兩版（決定論）：

- **幕一・碾壓**（第 1 屆首遇）：他輾過去。賽前首遇對話＋賽後對話（勝/敗版——玩家爆冷贏也要有版本，他的反應是人設試金石）。
- **幕二・被逼到牆邊**（第 2 屆準決賽）：「逼到牆邊」的張力**寫死在事件演出裡**，不依賴實際比分（該場為 bo3 關鍵戰，賽制自帶張力）。賽前＋賽後勝/敗版。
- **幕三・坦白**（第 3 屆決賽）：「我也曾在牆的這一邊。」勝敗皆成立——他動搖的是看見你不爬牆也站得住，不是輸球本身；敗版（你輸他贏、他卻在勝利裡說出這句）要寫出另一種重量。

### 1-3 鏡子/牆分版與幕三條件句（拍板）

- **幕一、幕三**依創角身高分「鏡子版」（你高＝嫉妒的鏡子）/「牆版」（你矮＝必須踩下去的牆）；**幕二共用**。身高門檻判定由實作端依現行身高資料合理提案、如實記錄。
- **幕三坦白的觸發語意讀「你怎麼贏他的」，不讀身高**（設計原則：教義被玩家的打法打破，不是被玩家的尺寸及格）。決定論條件句組，優先序：
  1. **轉 L 版**（最強版本）：玩家以 L 打進決賽 →「你連跳都不用跳……我砌的牆，你繞過去了。」（語意如此，措辭可精修）
  2. **打法版**：生涯數據中假動作得手/讀攔網佔比高（門檻由實作端依 box score 現有欄位提案）→ 指向「你讓我的高度沒用」。
  3. **基底版**：皆不符 → 基底坦白照走。
  - **長高變體**：三年身高成長超門檻時可作為附加一句的變體，**不得作為主判定**。
- 版本矩陣控制：分版軸＝（鏡子/牆）×（勝/敗）×（條件句組），只在拍板指定處展開，勿自行全積展開。

### 1-4 台詞品質與演出需求清單

- 台詞以**可引用**為標準（玩家會記住的句子，對標「爬不上來，是你不夠想」等級），不寫功能性過場句。
- **每幕產出演出需求清單**（例：幕二他第一次擦汗、幕三坦白的燈光語言），落檔隨結案快照交付——此清單＝4.5B 演出輪的輸入。本輪**只立骨不上肉**：演出以現有 dialogPlay/字卡/既有鏡位管線交付，不新建演出管線。

### 1-5 接線與周邊

- 賽前/賽後對話接線（W4 §2a 未做項）：宿敵場對陣畫面/賽後鏈掛三幕事件，沿 events.js 宣告式 when/lines＋dialogPlay；跨屆一次性旗標沿 `ONCE_EVENT_IDS` 範式。
- ace 反讀「被讀穿」體感已上線，三幕把「被讀」做成敘事事件（幕二/幕三台詞可回扣「他改線了」）。

## 2. 紀慕白（小白）支線——「不落地教」3 事件制

素材＝W3 快照 §7 案 B（第 3 屆手寫 L 新生 N2、160cm；球不落地就還沒輸；成長弧＝學會「有些球該放」）。

1. **事件一・入學宣言**（第 3 屆開幕）：不落地教亮相。寫作註記：他與宿敵是同一硬幣兩面（莊敬嶺信高度、小白信不落地，都把一件事信成全部）——對位不明說，押在台詞底下。
2. **事件二・期中衝突「該放的球」**：掛**真實數據決定論觸發**——他為追明顯救不回的球失位/丟分等可判事件累積 n 次後觸發。觸發條件與 n 值由實作端依現有事件流可判性提案、寫回結案快照如實記錄。與 L 改判機制互為表裡（封住哪條線＝放掉哪條線）。
3. **事件三・承認**（屆末）：信仰升級非放棄——「不落地」從執念變成選擇權。玩家三年級、他一年級，弧線收在玩家畢業前；生涯結算送別台詞回扣此弧。

- **轉 L 差分**：台詞差分不另開事件線——玩家轉 L＝師徒版/未轉＝旁觀版。
- **三人版轉位敘事**（玩家轉 L 時小守＋小白三人關係改寫）併入本包，僅轉 L 路徑觸發。
- 規格上限＝3 事件＋差分，**不加事件數**；台詞與演出需求清單標準同 §1-4。

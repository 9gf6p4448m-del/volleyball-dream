# 職業章批 4c 驗收凍結（2026-08-26）——二段時間差（案 C，地基級）

依據＝`pro-chapter-kickoff.md` 批 4 增補（三案全做）＋`pro-batch4-design-draft.md` 案 C。
本批動 sim 扣球判定＝地基級（design-brief 分工），實作品質要求最高。

- **F1 解鎖**：TECH_DEFS 新增職業章技術（名稱提案「二段時間差」）；職業章傳授事件
  （一生一次、dialogPlay 契約＋字在容器）；**未解鎖零可見**（無新按鈕/提示/判定）。
- **F2 機制**：玩家扣球起跳後的滯空窗內可做**第二段變向**（改打點/改線）——騙已起跳
  的攔網（對方攔網手依第一段判斷起跳，變向後攔不到原位置）。操作面設計屬實作提案
  （沿「走位＋時機＋方向三要素」哲學），但受兩條紀律凍結：
  1. ★不得做成「按早按晚」的時機懲罰軸★——大學卷 B7-3 已實測時機軸整條是負的；
     二段的本質是**變向選擇**（打哪裡），不是時機判定（按多準）。
  2. 代價非純增益：力量折損＋體力消耗大（**重度疲勞檔不可用**——接既有疲勞系統，
     疲勞可視化讓對手也讀得到你還能不能變向）。幅度屬提案。
- **F3 sim 紀律**：允許動 src/sim 扣球判定，但——AI 不使用此招（無 AI 觸發路徑）；
  未解鎖/未使用時**逐值無效果**（既有扣球路徑一行為都不變）；
  sim-hash＝`34772c06e02243fd` 不動；決定論不破（同 seed 同輸入逐 tick 相同）。
- **F4 攔網側的公平性**：攔網 AI 對變向的反應只能用**公開線索**（球/身體的真實運動
  狀態），不得讀玩家輸入意圖的私有狀態（反作弊鐵律）；也不得完全無反應（變向若
  永遠 100% 得利＝純增益違反 F2-2）。
- **F5 全套**：npm test 全綠（基準 1949＋新增）；改前紅照慣例（行為級＋壞版自證）；
  決定論測試（同 seed 兩次逐值相同）必附。
